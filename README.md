# ربات فروش اشتراک تلگرام

## راه‌اندازی روی Railway

### متغیرهای محیطی (Environment Variables)

در Railway این متغیرها را تنظیم کنید:

| متغیر | توضیح | مثال |
|-------|-------|------|
| `BOT_TOKEN` | توکن ربات از BotFather | `123456:ABC...` |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با کاما جدا) | `123456789,987654321` |
| `CARD_NUMBER` | شماره کارت برای پرداخت | `6037-1234-5678-9012` |
| `CARD_HOLDER` | نام صاحب کارت | `علی محمدی` |
| `PRICE_1GB` | قیمت پلن ۱ گیگ (تومان) | `350000` |
| `PRICE_2GB` | قیمت پلن ۲ گیگ (تومان) | `650000` |
| `PRICE_TEST_50MB` | قیمت تست ۵۰ مگ (تومان) | `45000` |
| `PRICE_TEST_100MB` | قیمت تست ۱۰۰ مگ (تومان) | `85000` |

### مراحل دیپلوی

1. این ریپو را Fork یا Clone کنید
2. در Railway یک پروژه جدید بسازید
3. ریپو GitHub خود را وصل کنید
4. متغیرهای محیطی بالا را وارد کنید
5. Deploy کنید

## دستورات ادمین

| دستور | کاربرد |
|-------|--------|
| `/admin` | باز کردن پنل مدیریت |
| `/addadmin <user_id>` | افزودن ادمین جدید |
| `/removeadmin <user_id>` | حذف ادمین |
| `/setbalance <user_id> <amount>` | تنظیم موجودی کاربر |
